# client

The web UI for team — a Next.js app for managing the task queue and monitoring workers.

## Dev

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
pnpm build
pnpm start
```

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [Geist](https://vercel.com/font) font
