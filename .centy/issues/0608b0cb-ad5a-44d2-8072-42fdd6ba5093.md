# Add Dockerfile to boot up the full system

## Goal

Create a `Dockerfile` (and likely a `docker-compose.yml`) that boots up all system services in one command, enabling easy local development and onboarding.

## Scope

- Identify all services/components that need to run (client, server, daemon, etc.)
- Write a `Dockerfile` for each service that doesn't already have one
- Write a `docker-compose.yml` that orchestrates all services together
- Ensure proper environment variable handling and service dependencies
- Verify the full system comes up correctly with a single `docker compose up`

## Acceptance Criteria

- `docker compose up` starts all services without manual steps
- Services can communicate with each other (correct networking/ports)
- README or inline comments document any required env vars or setup
