# Task output / log streaming support

Decide how to expose agent CLI output in the gRPC API.

Options to consider:
- `WatchTask` — server-streaming RPC to tail live output while a task is running
- `GetTaskOutput` — unary RPC to fetch stored output after completion
- Both

Logs were intentionally left out of the initial proto design. This issue tracks the follow-up decision and implementation.
