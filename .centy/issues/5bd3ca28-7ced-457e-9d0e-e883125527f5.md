# Add cspell spell checking with Husky pre-commit hook

Set up spell checking for the repo using cspell, wired into a Husky pre-commit hook via lint-staged. Uses Corepack + pnpm for Node tooling.

## Scope

- `package.json` — `packageManager: pnpm@10.33.0`, devDeps: `husky`, `cspell`, `lint-staged`; scripts: `"prepare": "husky"`; lint-staged config targeting `*.{rs,md,toml,json}` → `cspell lint --no-progress`
- `cspell.json` at repo root — language `en`, covers `**/*.{rs,md,toml,json}`, ignores `.centy/`, `target/`, `node_modules/`; seeds word list from `.centy/cspell.json`
- `.husky/pre-commit` — runs `pnpm lint-staged`
- `.gitignore` — add `node_modules/`

## Notes

- Corepack manages the pnpm version — contributors run `corepack enable` once, then `pnpm install`
- lint-staged ensures only staged files are checked on each commit (fast)
- `.centy/cspell.json` already has a project-specific word list; root config will inherit those words
